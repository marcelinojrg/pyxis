# QA-UX — Responsive, Accessibility, dan SEO

## Viewport

Uji semua halaman publik pada:

- [ ] 360 × 800.
- [ ] 768 × 1024.
- [ ] 1280 × 800.
- [ ] 1440 × 900.

Expected:

- [ ] Tidak ada horizontal overflow.
- [ ] Tidak ada teks/tombol terpotong.
- [ ] Menu mobile dapat dibuka dan ditutup.
- [ ] Gambar tidak pecah atau melampaui container.

## Keyboard

- [ ] Semua link/button dapat dicapai dengan Tab.
- [ ] Focus terlihat.
- [ ] Dialog dapat ditutup dengan Escape.
- [ ] Form dapat dikirim tanpa mouse.

## Semantik

- [ ] Setiap input memiliki label.
- [ ] Gambar memiliki alt yang sesuai.
- [ ] Heading berurutan.
- [ ] Error form terlihat dan terhubung ke field.
- [ ] Kontras teks terbaca.

## SEO

- [ ] Title dan description benar.
- [ ] Canonical benar.
- [ ] Open Graph image benar.
- [ ] `/sitemap.xml` berhasil.
- [ ] `/robots.txt` berhasil.
- [ ] 404 memakai halaman error yang ramah.
